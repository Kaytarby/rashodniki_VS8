# Расходники Jetta VS8

Одностраничный справочник расходных материалов для Jetta VS8 (FAW-Volkswagen):
оригинальные и альтернативные артикулы, живые ссылки на Ozon / Wildberries / официальные
сайты производителей, отзывы Oil-Club, оценки владельцев и добавление своих позиций.

**Онлайн:** https://rashodniki-jetta-vs8.vercel.app
**Локально:** откройте `index.html` — сборка не нужна, зависимостей нет.
Оценки и добавленные посетителями позиции хранятся в Supabase и видны всем.

## Что внутри

- `index.html` — весь сайт в одном файле: разметка, стили и логика. Без внешних CDN и шрифтов,
  поэтому работает офлайн и с локального диска (`file://`).
- `data/Расходники Jetta VS8.md` — исходная таблица, из которой собран каталог (100 позиций, 7 разделов, 24 подраздела).

## Хранение данных: общая база + офлайн-режим

Сайт работает в двух режимах, переключение автоматическое.

**Онлайн (Supabase).** Анонимный `client_id` (UUID в `localStorage`) — это «ключ» к своим
позициям и оценкам, аккаунт не нужен. Читают все, пишут через RPC-функции с проверкой владельца.

| Объект | Назначение |
|---|---|
| `public.parts` | позиции, добавленные посетителями (RLS включён, прямой доступ закрыт) |
| `public.votes` | оценки 1–5, по одной на позицию и устройство |
| `rpc/list_parts`, `rpc/rating_summary`, `rpc/get_my_votes` | чтение каталога, сводка оценок, мои оценки |
| `rpc/add_part`, `rpc/update_part`, `rpc/delete_part` | CRUD своих позиций с валидацией и лимитом 30 добавлений/час |
| `rpc/set_vote` | поставить или изменить оценку |
| `rpc/reset_my_data` | удалить все свои данные |

Прямой `select` к таблицам для роли `anon` отозван: только функции. Лимиты и проверки
длины полей живут на сервере, поэтому их не обойти из консоли браузера.

**Офлайн / `file://`.** Если сервер недоступен, всё сохращается в `localStorage`
(`jv8.ratings.v1`, `jv8.useritems.v1`, `jv8.mine.v1`, `jv8.theme.v1`) — статус в футере
показывает «Локальный режим». Копию данных можно выгрузить в JSON.

## Деплой

| Что | Где |
|---|---|
| Сайт | Vercel, проект `rashodniki-jetta-vs8`, ветка `arena/3490c366-rashodniki-vs8` → production |
| База | Supabase `lmbeuefieivvvfdxskln` (eu-central-1), проект `rashodniki-jetta-vs8` |

Статика без сборки: Vercel отдаёт `index.html` и `assets/` как есть.
Ключ в `index.html` — публичный `anon`, доступ ограничен RLS и RPC-функциями.
Push в ветку автоматически запускает новый деплой.

## Запуск локально

```bash
python3 -m http.server 8000
# http://localhost:8000
```

Или просто откройте `index.html` файлом.

## Источник и оговорки

Артикулы, цены и ссылки перенесены из таблицы «Расходники Jetta VS8.xlsx» (14 листов) без изменений.
Цены в рублях за литр масла ориентировочные. Метка «Оригинал» ставится автоматически артикулам
VAG и FAW-Volkswagen; «Выбор редакции» — маслам с лучшими результатами лабораторных разборов
Oil-Club; «сравнить» — позициям, которым в исходной таблице требуется проверка применимости.
Перед покупкой сверяйте артикул с VIN у продавца.
