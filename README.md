# Расходники Jetta VS8

Одностраничный справочник расходных материалов для Jetta VS8 (FAW-Volkswagen):
оригинальные и альтернативные артикулы, живые ссылки на Ozon / Wildberries / официальные
сайты производителей, отзывы Oil-Club, оценки владельцев и добавление своих позиций.

**Демо:** откройте `index.html` в браузере — сборка не нужна, зависимостей нет.

## Что внутри

- `index.html` — весь сайт в одном файле: разметка, стили и логика. Без внешних CDN и шрифтов,
  поэтому работает офлайн и с локального диска (`file://`).
- `data/Расходники Jetta VS8.md` — исходная таблица, из которой собран каталог (100 позиций, 7 разделов, 24 подраздела).

## Возможности

| Раздел | Детали |
|---|---|
| Каталог | 7 разделов и 24 подраздела: масло 0W-20, фильтры, тормоза, подвеска, свечи и ГРМ, антифриз G12evo, щётки |
| Поиск | По артикулу, бренду, названию и комментарию; подсветка совпадений, `⌘K` / `Ctrl+K` / `/` |
| Фильтры | «Мои позиции», «Мои оценки», сортировка по рейтингу, цене и бренду |
| Оценки | 1–5 баллов, средний балл и количество оценок, стрелки клавиатуры внутри группы звёзд |
| Ссылки | Ozon, WB, официальный сайт, Oil-Club — в новой вкладке, с `rel="noopener nofollow"` |
| OEM-коды | Раскрывающиеся списки кодов для колодок и задних дисков, копирование в один клик |
| Свои позиции | Форма добавления, редактирование, удаление, привязка к нужному подразделу |
| Перенос данных | Экспорт и импорт JSON, полный сброс |
| Оформление | Светлая и тёмная тема, `prefers-reduced-motion`, печатная версия, тач-таргеты, фокус-ринги |

## Хранение данных

Оценки и добавленные позиции лежат в `localStorage` браузера:
`jv8.ratings.v1`, `jv8.useritems.v1`, `jv8.mine.v1`, `jv8.theme.v1`.
Сервера и аккаунтов нет — данные не покидают устройство. Копию можно выгрузить кнопкой
«Выгрузить JSON» в футере и загрузить на другом устройстве.

## Запуск локально

```bash
python3 -m http.server 8000
# http://localhost:8000
```

Или просто откройте `index.html` файлом.

## Источник и оговорки

Артикулы, цены и ссылки перенесены из таблицы «Расходники Jetta VS8.xlsx» (14 листов) без изменений.
Цены в рублях за литр масла ориентировочные. Метка «Оригинал» ставится автоматически артикулам
VAG и FAW-Volkswagen; «Выбор редакции» — маслам с лучшими результатами лабораторных разборов
Oil-Club; «сравнить» — позициям, которым в исходной таблице требуется проверка применимости.
Перед покупкой сверяйте артикул с VIN у продавца.
